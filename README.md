# Выручка ресторанов из Saby

## Что умеет
- Загружает реализацию напрямую из внутреннего отчета Saby.
- Получает точные суммы по складам кухни и бара с учетом возвратов.
- По умолчанию показывает текущий день.
- Хранит накопительный архив: исторические дни не запрашиваются повторно.
- Дает быстрый выбор: сегодня, вчера, текущая/прошлая неделя и текущий/прошлый месяц.
- Агрегирует выручку по схеме `дата + ресторан + склад`.
- Показывает:
  - общую выручку,
  - количество ресторанов,
  - количество дней,
  - график по дням,
  - таблицу с фильтрами по ресторану и периоду.

## Как запустить
1. Сохраните параметры приложения Saby в `.env`.
2. Положите сервисный ключ в файл с расширением `.key`.
3. Выполните `npm start`.
4. Откройте `http://127.0.0.1:4173`.

## Важно
- На GitHub Pages архив хранится отдельными файлами по месяцам в `data/`.
- GitHub Actions ежедневно в 05:00 МСК фиксирует данные за вчера.
- Кнопка «Показать данные» перечитывает опубликованный архив; секреты Saby браузеру не передаются.
- Для локального запроса напрямую к Saby запускайте сайт через `server.mjs`.
- `.env`, `*.key` и `*.har` исключены из Git.
- В GitHub Actions используются защищенные секреты `SABY_APP_CLIENT_ID`,
  `SABY_APP_SECRET` и `SABY_SERVICE_KEY`.
- SheetJS используется только для экспорта результата в Excel.
- `SalesAnalytics.GetData` — внутренний метод Saby; при изменении его формата потребуется обновить адаптер.
